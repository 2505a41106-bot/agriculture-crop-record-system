# Agriculture Crop Record System

A beginner-friendly Flask website for managing crop records.

## Features
- Dashboard statistics
- Add, view, search, update and delete crop records
- Clear all records
- CSV file storage
- Input validation
- Responsive design

## Run in VS Code
1. Install Python 3.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run `pip install -r requirements.txt`
5. Run `python app.py`
6. Open `http://127.0.0.1:5000` in your browser.

Data is stored in `data/crops.csv`.
